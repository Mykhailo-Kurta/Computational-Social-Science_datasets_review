# Canada Climate 2025 Dashboard

A simple front-end data visualization project using HTML, CSS and JavaScript.

## Technologies

- HTML
- CSS
- JavaScript
- Chart.js
- Leaflet
- OpenStreetMap tiles
- Python + pandas for one-time data preparation

There is no database and no backend.

## Project structure

```text
canada-climate-dashboard/
├── index.html
├── style.css
├── script.js
├── prepare_data.py
├── data.json          # generated by prepare_data.py
└── README.md
```

## Data sources

The project uses:

- 2025 Canadian weather observations
- 1991–2020 Canadian Climate Normals
- validated selected stations

## How to generate `data.json` and 

The default paths in `prepare_data.py` point to:

```text
D:\Desktop\Computational Social Science\Hometask1\
```

Make sure these files exist there:

```text
aafc_aac_climat_2025.csv
1991-2020_Canadian_Climate_Normals_CANADA_Data.csv
selected_stations.csv
station_validation.csv
```

Then run:

```powershell
py prepare_data.py
```

If your Python environment uses a different interpreter, run the script with that interpreter instead.

## How to run the website

Because the page loads `data.json` and , do not open `index.html` directly with `file://`.

From the project folder run:

```powershell
py -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Visualizations

1. Monthly temperature overview
2. Interactive map of all assigned stations
3. Monthly temperature anomalies versus 1991–2020 normals
4. Monthly precipitation anomalies versus 1991–2020 normals
5. Temperature ranking
6. Precipitation ranking

The analytical charts use the validated selected stations. The map shows all stations that were assigned to a Canadian province or territory during the station-validation step.


### Data files generated by `prepare_data.py`

The script creates two browser-ready files:
- `data.json` — compact analytical data only.
-  — a simplified Canada outline used only by the map.

The large 2025 CSV and climate normals stay outside the web folder and are never sent to the browser.
